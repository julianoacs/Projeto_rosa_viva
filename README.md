# Projeto Rosa Viva

O projeto Rosa Viva – Conectando Mulheres à Prevenção foi desenvolvido com o objetivo de criar uma plataforma digital educativa e acessível voltada à conscientização sobre o câncer de mama.
A proposta busca oferecer informações confiáveis, incentivar hábitos preventivos e proporcionar uma experiência acolhedora e intuitiva para mulheres de diferentes faixas etárias e níveis de familiaridade com a tecnologia.
Durante o desenvolvimento, foram considerados conceitos de Experiência do Usuário (UX), Usabilidade e Acessibilidade, utilizando como principal referência os 10 Princípios de Usabilidade de Jakob Nielsen, aplicados diretamente nas decisões de interface e interação.
